Reproduce & verify

复现与验证协议

A · Re-verify this package on your machine (<10 seconds, no repo needed)

A · 在你机器上复验本包（<10 秒，无需仓库）

cd 官网-双击打开
bash verify/run.sh          # 8 gates, bundle-scoped, all must print PASS

The gates read only files inside this folder: corpus facts 3-way cross-checked (data ↔ dashboard ↔ paper anchors), lexicon definitions re-checked term-by-term, direction assertions (flat pre / positive post / CIs finite), sha256 manifest over all 22 shipped files, 31 citations vs the TOFU liveness cache, dashboard payload recomputed against results. Blank or delete anything → the gates go red.

八道门只读本文件夹内文件：语料事实三源交叉（数据↔仪表盘↔论文锚点）、词表逐核心词定义复核、方向断言（前期平/后期正/置信区间有限）、22 个发货文件全量 sha256 清单、31 条引用对活性缓存、仪表盘 payload 对 results 独立重算。任何文件被改动或移除 → 对应门必红。

B · Full pipeline rebuild (needs the repo, ~13 min)

B · 完整流水线重建（需仓库，约 13 分钟）

bash run_all.sh --full   # download → prep → features → similarity → stats(boot=1000) → figures → payload → papers → bundle

Fully seeded; every number in this release is machine-injected from `results.json` (11 `<!--K:-->` anchors, triangulated). The independent review chain (3 QA rounds, ship-loop 4 clean rounds, incident log) lives in the repo under `work/`.

全链路固定种子；本发布每个数字都从 results.json 机器注入（11 个 K 锚三方互检）。独立评审链（QA 三轮、发布循环四轮全绿、事故记录）在仓库 work/ 下。
